How This Site Works

Behind the nostalgia, this desktop is real software. Open a book to see how a part of it works, and why it's built that way.

No framework, on purpose

Plain HTML, CSS and JavaScript: no React, no Tailwind, no bundler. The only build step is a short esbuild script, and it minifies each file on its own rather than bundling them. The pages call global functions straight from their HTML, and a bundler would rename or drop those and quietly break buttons.

The build also reports every file's Brotli size, because that's what Cloudflare actually sends.

  • Read build.js
A window manager, written from scratch

Every window on this desktop registers with one small module, so they all open, stack, drag, minimize and maximize the same way, and the taskbar has a single place to learn what's open.

The details are where it earns its keep: a drag keeps going when the pointer crosses an embedded page, a window can't be dragged off the top of the screen, and minimizing hands keyboard focus to the window's taskbar button instead of dropping it.

  • Read window-manager.js
Data that keeps itself fresh

The site is static files, yet it's never stale. Scheduled GitHub Actions read Spotify, Trakt and my coffee loyalty card, then commit the results to the repository as JSON for the pages to read. Bots have made most of this repo's commits.

The coffee job runs up to three times a day and stops once it has the day's numbers. It retries a failed request, but never a refused login: trying a bad password again could lock the account.

  • Browse the workflows
An email address scrapers can't read

My email address isn't anywhere in this page's source. Decrypt Contact Info first asks Cloudflare Turnstile whether you're human, then sends its token to a small Cloudflare Worker.

The Worker checks the token with Cloudflare, including that it was issued for this action on this site, and only then returns the address. A token solved anywhere else doesn't count.

  • Go to Contact Me
  • Read worker.js
Tested before every commit

A git hook builds the site and runs the whole test suite before each commit: Node's built-in test runner for the Worker and the data fetchers, and Playwright for the pages themselves.

The smoke test fails on any console error from the site's own code, and it starts the screensaver straight away, so code that normally waits for three idle minutes still runs. Playwright drives the Microsoft Edge already on the machine instead of downloading a browser a corporate proxy would block.
